# مؤسسة الفجر الخيرية الاجتماعية - نظام إدارة حضور الموظفين وإجازاتهم

نظام متكامل لإدارة شؤون الموظفين، الحضور والانصراف، التحقق من النطاق الجغرافي عبر GPS، طلبات الإجازات والأعذار، وحساب التأخير والتقارير الميدانية.

---

## 🚀 كيفية تشغيل المشروع بعد تحميله وفك الضغط

### ❓ سبب ظهور شاشة بيضاء عند فتح ملف `index.html` مباشرة:
مشاريع الويب الحديثة المبنية بـ **React 19 + TypeScript + Vite** لا تعمل بمجرد النقر المزدوج على `index.html` عبر متصفح الملفات (`file:///`)، نظراً لأن المتصفحات تمنع استدعاء ملفات TypeScript ووحدات ES Modules محلياً لأسباب أمنية (CORS Restrictions)، وتتطلب بيئة تشغيل محلية وسيطة.

---

### ⚡ طريقة التشغيل المباشرة (نقرة واحدة على Windows):
1. تأكد من تثبيت **[Node.js](https://nodejs.org)** (مجاني ومتاح لكافة الأنظمة، يُفضل إصدار LTS).
2. انقر نقراً مزدوجاً على الملف:
   ```bash
   تشغيل_الموقع.bat
   ```
   *(أو ملف `start.bat`)*
3. سيقوم البرنامج تلقائياً بتثبيت الحزم المطلوبة وتشغيل السيرفر وفتح الموقع في متصفحك على:
   `http://localhost:3000`

---

### 💻 طريقة التشغيل عبر سطر الأوامر (Terminal / CMD):
إذا كنت تستخدم Mac أو Linux أو تفضل تشغيله يدوياً:

```bash
# 1. تثبيت المكتبات (لأول مرة فقط)
npm install

# 2. تشغيل خادم التطوير المحلي
npm run dev
```
ثم افتح متصفحك وتوجه إلى:
`http://localhost:3000`
