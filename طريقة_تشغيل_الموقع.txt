================================================================================
دليل تشغيل نظام حضور وانصراف مؤسسة الفجر الخيرية الاجتماعية على جهازك
================================================================================

أولاً: سبب ظهور شاشة بيضاء عند فتح ملف index.html مباشرة:
---------------------------------------------------------
مشاريع الويب وتطبيقات الأنظمة الحديثة المبنية بتقنيات (React + TypeScript + Vite)
تختلف عن صفحات الويب البسيطة القديمة (HTML ثابتة).
- المتصفحات لا تستطيع قراءة ملفات الكود الحديثة (.tsx) أو تشغيل الوحدات البرمجية مباشرة
  عند النقر المزدوج عبر مسار القرص المباشر (file:///C:/...) بسبب قيود الأمان في المتصفحات (CORS Policy).
- لذلك تحتاج هذه الأنظمة إلى تشغيل خادم محلي (Local Dev Server) ليقوم بالترجمة الفورية وعرض الموقع.


ثانياً: طريقة تشغيل الموقع بنقرة واحدة (الطريقة الأسهل للجميع):
---------------------------------------------------------
1. تأكد من وجود برنامج Node.js مثبت على جهازك (تحتاجه لمرة واحدة فقط وهو مجاني تماماً):
   إذا لم يكن مثبت لديك، حمله من الموقع الرسمي:
   👉 https://nodejs.org  (اختر النسخة الموصى بها LTS).

2. انقر نقراً مزدوجاً (Double Click) على الملف:
   👉 "تشغيل_الموقع.bat"  (أو "start.bat")

3. سيقوم الملف تلقائياً بتثبيت الحزم وتشغيل الخادم وفتح الموقع في متصفحك فوراً على الرابط:
   👉 http://localhost:3000


ثالثاً: طريقة التشغيل اليدوية عبر سطر الأوامر (CMD / Terminal):
---------------------------------------------------------
إذا كنت تفضل استخدام موجه الأوامر:
1. افتح موجه الأوامر (Terminal أو CMD أو PowerShell) داخل مجلد المشروع المفكوك ضغطه.
2. اكتب الأمر التالي واضغط Enter لتثبيت المكتبات (لأول مرة فقط):
   npm install

3. بعد اكتمال التثبيت، اكتب الأمر التالي لتشغيل الموقع:
   npm run dev

4. افتح المتصفح (Chrome, Edge, Firefox) واذهب إلى الرابط:
   http://localhost:3000
